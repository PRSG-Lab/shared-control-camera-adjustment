# Ready-made reference products

Generated by release 1.1.0 from the retained authoritative result data, using MATLAB R2026a Update 4 on 2026-09-30. No new production camera fits were performed for these products.

- `figures/Figure2` through `Figure6`: current manuscript numerical figures.
- `figures/FigureS1` through `FigureS13`: retained companion analyses.
- Each figure: PDF, 600-dpi PNG, editable FIG and numeric `_data.mat`.
- `tables/Table1` through `Table5`: main tables; S1–S5 retain archival companion definitions.
- Additional CSV files provide full-precision diagnostics and fit accounting.
- `figures/captions.txt` and `figure_manifest.json`: captions and numerical source mappings.

Author-prepared Figure 1 is excluded. These files are conveniences, never inputs to the calculation. `RUN_REFERENCE` regenerates them from the MAT files under `data/`. `RUN_PAPER` regenerates the experiments from synthetic observations. The numerical MATLAB renderings are not pixel-identical copies of the original manuscript artwork.
